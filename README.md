# Dolphin Friends Web

## English

Dolphin Friends Web is a social web app created for **Sunbeam Managua** on **August 29th**.

### Demo

Live demo: https://dolphinfriends.navarroweb.net/

### App functionality

- User registration and login with Firebase Authentication.
- Personalized feed with community posts.
- Create and publish new posts.
- Like/unlike posts.
- Session handling (login/logout) and protected pages.
- Friendly, dolphin-themed UI for young users.

### Tech stack

- **Frontend:** HTML5, CSS3, JavaScript (ES Modules)
- **Backend services:** Firebase Authentication, Cloud Firestore
- **Hosting/demo deployment:** Static web hosting (demo URL above)

### Project structure

- `/templates`: Main app screens (landing, login, register, feed, new post, profile).
- `/static/js`: Authentication, Firebase setup, and post logic.
- `/static/css`: Shared styling resources.
- `/static/img`: App images and branding assets.

## Español

Dolphin Friends Web es una aplicación web social creada para **Sunbeam Managua** el **29 de agosto**.

### Demo

Demo en vivo: https://dolphinfriends.navarroweb.net/

### Funcionalidades de la app

- Registro e inicio de sesión con Firebase Authentication.
- Feed personalizado con publicaciones de la comunidad.
- Creación y publicación de nuevos posts.
- Dar y quitar “me gusta” en publicaciones.
- Manejo de sesión (login/logout) y páginas protegidas.
- Interfaz amigable con temática de delfines para usuarios jóvenes.

### Stack tecnológico

- **Frontend:** HTML5, CSS3, JavaScript (ES Modules)
- **Servicios backend:** Firebase Authentication, Cloud Firestore
- **Hosting/despliegue demo:** Hosting web estático (URL de demo arriba)

### Estructura del proyecto

- `/templates`: Pantallas principales de la app (inicio, login, registro, feed, nuevo post, perfil).
- `/static/js`: Lógica de autenticación, configuración de Firebase y posts.
- `/static/css`: Recursos de estilos compartidos.
- `/static/img`: Imágenes y recursos de marca.
